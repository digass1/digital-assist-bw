# Digital Assist BW — Prototype v2

This version separates the frontend into:
- `index.html` — page structure/content
- `css/style.css` — presentation and responsive design
- `js/app.js` — interactive behaviour

This is still a prototype. Payments are simulated and no real customer information should be entered.

The next learning stages are backend, database, authentication, secure file storage, and payment integration.
